# Mobile Branding Landing Page (HTML/CSS/JS)

밝고 깔끔한 톤의 모바일 우선 개인 브랜딩 랜딩 페이지입니다. 정적(plain) 파일 3개로 구성되어 별도 빌드 없이 바로 사용할 수 있어요.

## 목적

부동산 데이터를 기반으로 인사이트를 만들고, 아래 3가지 역량을 모바일에서도 보기 좋게 소개합니다.

1. 부동산 경매 관련 예측 AI 모델 개발
2. 부동산 데이터 활용 경력 5년차
3. 데이터 엔지니어링 풍부

커피챗/이메일 CTA도 함께 제공합니다. 커피챗은 구글폼 링크로 연결되도록 되어 있습니다.

## 프로젝트 구조

- `index.html` : 페이지 구조/콘텐츠
- `styles.css` : 레이아웃/스타일(모바일 우선, 카드형 섹션, 버튼 디자인)
- `main.js` : 햄버거 메뉴 토글, 스크롤 리빌, CTA 클릭 토스트/동작, 푸터 연도 자동 반영

## 시작하기(로컬에서 바로 보기)

1. `index.html` 파일을 브라우저에서 직접 열어보세요.
2. 모바일 폭(대략 360px~480px)에서 레이아웃이 자연스럽게 보이는지 확인합니다.

## 커스터마이즈

### 1) 브랜드명/이름 변경

`index.html`에서 아래를 수정하세요.

- 상단 헤더: `.brand-name` (`Your Name`)
- 푸터: `.footer-brand` (`Your Name`)

### 2) 커피챗(구글폼) 링크 변경

`index.html`에서 아래 2개 버튼의 `href`를 수정하세요.

- `#coffeeChatBtn`
- `#coffeeChatBtn2`

현재 기본값은 아래 구글폼으로 연결되어 있습니다.

- https://forms.gle/zVVh5E8YseYMzWMK9

### 3) 이메일 링크 변경

`index.html`에서 `mailto:`로 시작하는 이메일 링크를 수정하세요.

- 상단 CTA 버튼(이메일로 문의)
- 하단 연락 섹션 이메일 버튼

## 동작 확인 체크리스트(권장)

- 햄버거 메뉴 열기/닫기 동작
- 메뉴 링크 클릭 시 해당 섹션으로 스크롤 후 메뉴 닫힘
- 커피챗 버튼 클릭 시(구글폼 링크) 정상 이동(새 탭)
- 이메일 버튼 클릭 시(`mailto:`) 메일 앱/링크 동작
- 360px~480px 폭에서 카드/버튼이 깨지지 않는지 확인
